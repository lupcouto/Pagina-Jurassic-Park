# 🦖 Página Jurassic Park

Projeto desenvolvido para a disciplina **Desenvolvimento Front-End**, com o objetivo de praticar **HTML** e **CSS** na criação de uma página inspirada no universo de *Jurassic Park*.

---

## 🌐 Tecnologias utilizadas
- HTML5  
- CSS3  

---

## 💡 Sobre o projeto
A página apresenta um design temático baseado no filme **Jurassic Park**, explorando conceitos de **estruturação semântica**, **estilização** e **posicionamento de elementos**.
